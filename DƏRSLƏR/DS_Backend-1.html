1. Backend nədir və bu dərs nə verir

NƏ EDƏCƏYİK

Bu dərsdə sıfırdan işlək bir backend quracağıq: NestJS 12 layihəsi yaradacaq, Prisma 7 ilə arti_baza-ya bağlayacaq və ilk endpoint-i curl ilə sınayacağıq.

NİYƏ LAZIMDIR

Baza birbaşa brauzerdən əlçatan deyil — və olmamalıdır. Əgər brauzer birbaşa PostgreSQL-ə qoşulsaydı, bazanın şifrəsi hər istifadəçinin brauzerində olardı. Backend bu işi öz üzərinə götürür:

ProblemBackend necə həll edir
Baza şifrəsi açıq düşərŞifrə yalnız serverdə qalır
Hər kəs hər şeyi silə bilərRol yoxlaması (RBAC)
Məlumat formatsız gələrValidasiya (DTO)
Dəyişikliyin izi qalmazAudit jurnalı
3 tətbiq (veb, mobil, AI) ayrı-ayrı SQL yazarBir API — hamı onu işlədir
OLMASA NƏ OLAR

Frontend birbaşa bazaya qoşulmalı olardı. Nəticədə:

  • Baza şifrəsi localStorage-da və ya JavaScript faylında görünərdi;
  • Hər istifadəçi bazanın bütün cədvəllərini görərdi;
  • Validasiya yox olardı — istənilən zibil məlumat bazaya düşərdi;
  • Mobil tətbiq üçün hər şey sıfırdan yazılmalı olardı.
İZAH — NestJS nədir?

NestJS — Node.js üçün strukturlu backend framework-üdür. Express sadədir, lakin böyük layihədə kod qarışır. NestJS əvvəlcədən qurulmuş arxitektura verir: modul, servis, controller, guard, interceptor.

AnlayışNədirBənzətmə

ServiceBiznes məntiqi, bazaya müraciətAşpaz
ModuleOnları bir yerə yığırŞöbə
Guardİcazəni yoxlayırMühafizəçi
PipeMəlumatı yoxlayır/çevirirKeyfiyyət nəzarəti
InterceptorƏvvəl/sonra işləyirJurnalist
Bu dərsin sonunda http://localhost:4000/api/v1/struktur/merkezler ünvanı real bazadan real məlumat qaytaracaq.

import { PrismaService } from '../prisma/prisma.service.js';

/** Bazadan gelen setir — TypeScript tipi */
export interface Merkez {
  id: number;
  ad: string;
  tip: string | null;
  unvan: string | null;
  telefon: string | null;
  email: string | null;
  aktiv: boolean;
}

@Injectable()
export class StrukturService {
  constructor(private readonly prisma: PrismaService) {}

  /** Butun merkezler */
  async merkezler(): Promise<Merkez[]> {
    return this.prisma.$queryRaw<Merkez[]>`
      SELECT id::int, ad, tip, unvan, telefon, email, aktiv
      FROM struktur.merkezler
      ORDER BY id
    `;
  }

  /** Bir merkez — tapilmasa 404 */
  async merkez(id: number): Promise<Merkez> {
    const setirler = await this.prisma.$queryRaw<Merkez[]>`
      SELECT id::int, ad, tip, unvan, telefon, email, aktiv
      FROM struktur.merkezler
      WHERE id = ${id}
    `;
    if (!setirler.length) {
      throw new NotFoundException(`Merkez tapilmadi: id=${id}`);
    }
    return setirler[0];

    return this.prisma.$queryRaw<

      FROM struktur.merkezler m
      LEFT JOIN struktur.shobeler s ON s.merkez_id = m.id
      GROUP BY m.ad
      ORDER BY shobe_sayi DESC
    `;
  }
}

17. CAST qaydası — BigInt, Numeric, Date

NƏ EDƏCƏYİK

PostgreSQL və JavaScript tipləri üst-üstə düşmür. Bunu düzəltmək üçün SQL-də cast edəcəyik.

⚠️ BU, ƏN ÇOX RASTLANAN BACKEND XƏTASIDIR

PostgreSQL BIGINT qaytarır, JavaScript-də isə o BigInt tipinə çevrilir — və JSON.stringify() onu serializasiya edə bilmir.

PG tipiJS-də problemCastNəticə

İZAH — niyə ::float8?

NUMERIC tipi PostgreSQL-də dəqiq onluq ədəddir — pul hesablamaları üçün idealdır. JavaScript-də isə belə tip yoxdur, ona görə drayver onu sətir kimi ötürür (dəqiqliyi itirməmək üçün).

import { Injectable, NotFoundException } from '@nestjs/common';
import { PrismaService } from '../prisma/prisma.service.js';

export interface Merkez {
  id: number; ad: string; tip: string | null;
  unvan: string | null; telefon: string | null;
  email: string | null; aktiv: boolean;
}

@Injectable()
export class StrukturService {
  constructor(private readonly prisma: PrismaService) {}

  async merkezler(): Promise<Merkez[]> {
    return this.prisma.$queryRaw<Merkez[]>`
      SELECT id::int, ad, tip, unvan, telefon, email, aktiv
      FROM struktur.merkezler ORDER BY id`;
  }

  async merkez(id: number): Promise<Merkez> {
    const s = await this.prisma.$queryRaw<Merkez[]>`
      SELECT id::int, ad, tip, unvan, telefon, email, aktiv
      FROM struktur.merkezler WHERE id = ${id}`;
    if (!s.length) throw new NotFoundException(`Merkez tapilmadi: id=${id}`);
    return s[0];
  }
}

function saxtaPrisma() {

}

describe('StrukturService', () => {

    prisma = saxtaPrisma();
    service = new StrukturService(prisma);
  });

  it('merkezler siyahisini qaytarir', async () => {
    prisma.$queryRaw.mockResolvedValue([
      { id: 1, ad: 'Elmi katiblik', aktiv: true },

    expect(netice).toHaveLength(1);

    ]);

    const netice = await service.merkez(2);

    expect(netice.id).toBe(2);
  });

  it('SQL-e parametr oturur (SQL injection qorumasi)', async () => {
    prisma.$queryRaw.mockResolvedValue([]);
    await service.merkez(5).catch(() => null);

    const cagiris = prisma.$queryRaw.mock.calls[0];
    // Prisma template literal: (strings, ...parametrler)
    expect(cagiris.length).toBeGreaterThan(1);
    expect(cagiris[1]).toBe(5);
  });
});
